# 新爱莉都棋牌室

新爱莉都棋牌室是一个 AstrBot 群聊桌游插件，目标是让真人玩家和米哈游角色卡 AI 坐在同一张牌桌上游玩。当前包含：

- 狼人杀：9 人局，支持真人与角色卡 AI 混合。
- 璀璨宝石：2-4 人经典规则，支持真人与角色卡 AI 混合，使用 SQLite 保存牌局快照。

核心原则：这是“和角色本人玩桌游”，不是“通用高手套角色皮”。角色身份、声纹、关系和 OOC 边界优先于胜率；AI 可以菜、可以犹豫、可以失误，但所有资源、买牌、贵族、终局结算都由规则引擎确定。

## 快速开始

### 璀璨宝石

```text
/创建璀璨房间 4
/加入璀璨
/璀璨加入角色AI 三月七
/璀璨补满AI
/开始璀璨
```

常用行动：

```text
/拿宝石 白 蓝 绿
/拿宝石 红 红
/保留牌 T1-1
/保留牌 T2
/购买牌 T3-4
/购买牌 R1
/选择贵族 N1
/丢宝石 白 蓝
/璀璨状态
```

### 狼人杀

```text
/创建房间
/加入房间
/加入角色AI 三月七
/补满角色AI
/开始游戏
```

## 璀璨宝石规则覆盖

- 支持 2-4 人。
- 2/3/4 人分别使用每色 4/5/7 枚普通宝石，金币固定 5 枚。
- 2/3/4 人分别翻出 3/4/5 位贵族。
- 发展卡三级牌堆各自洗牌，每级市场公开 4 张，买走或保留公开牌后自动补牌。
- 回合行动四选一：拿 3 枚不同色宝石、拿 2 枚同色宝石、保留 1 张发展卡、购买 1 张发展卡。
- 拿 2 枚同色宝石时，该颜色银行中必须至少有 4 枚。
- 保留牌上限为 3 张；保留时若金币未空，获得 1 枚金币；可保留公开牌或盲保留某级牌堆顶牌。
- 金币作为万能宝石支付购买差额。
- 回合结束最多保留 10 枚宝石，超出时必须使用 `/丢宝石` 退回银行。
- 购买发展卡后立即获得永久折扣与分数；若满足贵族条件，贵族自动来访。
- 同时满足多位贵族时，玩家必须用 `/选择贵族 N1` 选择其中一位。
- 任一玩家达到 15 分后触发最终轮，补齐本轮剩余玩家行动后结算。
- 最高分胜；平分时买过的发展卡更少者胜；仍相同则并列胜利。

## 璀璨宝石文字 UI

`/璀璨状态` 会展示：

- 当前阶段、当前行动玩家、银行宝石。
- 公开贵族要求。
- T1/T2/T3 市场牌位、分数、颜色和成本。
- 每位玩家的分数、永久宝石、手中宝石、预留数量、买牌数量。
- 每位玩家的预留牌明细，包括 R 位、颜色、分数和成本。
- 待丢宝石或待选贵族的明确命令提示。

## 角色卡 AI

角色 AI 来自 `data/skills` 中已有米哈游角色卡。插件会读取：

- `manifest.json`
- `SKILL.md`
- `personality.md`
- `interaction.md`
- `relations.md`
- `conflicts.md`
- `memory.md`
- `tabletop_werewolf.md`
- `tabletop_splendor.md`

`tabletop_splendor.md` 是可选但推荐的璀璨宝石适配文件。缺失时，插件会用通用角色卡裁剪规则生成桌游人格。

AI 决策流程：

1. 规则引擎生成当前合法动作清单。
2. LLM 只从合法动作中选择，并附一句角色口吻的短发言。
3. 引擎重新校验动作；非法或无法解析时使用带随机性的合法兜底动作。
4. 游戏结算、付款、补牌、贵族访问、终局全部由 Python 引擎执行。
5. 游戏结束后，角色 AI 会写入一条短牌桌记忆，供以后同角色再次上桌时参考。

## 数据存储

棋牌室会把活跃房间写入 AstrBot 插件数据目录，插件正常重载不会主动结束等待中或进行中的房间。

璀璨宝石快照：

```text
data/plugin_data/astrbot_plugin_new_elysium_cardroom/splendor/splendor.sqlite3
```

狼人杀快照：

```text
data/plugin_data/astrbot_plugin_new_elysium_cardroom/werewolf/werewolf_rooms.sqlite3
```

插件重载后会恢复等待中或进行中的房间。下一条群消息会自动刷新主动发送所需的通信上下文；狼人杀的计时器是运行时任务，重启期间不会继续倒计时，恢复后由后续玩家行动、AI 行动或阶段切换继续推进。

审计、角色记忆和资产清单仍保存在同一插件数据目录下。

### 狼人杀

狼人杀保留原有命令：`/创建房间`、`/加入房间`、`/加入角色AI`、`/补满角色AI`、`/开始游戏`、`/查角色`、`/办掉`、`/验人`、`/救人`、`/毒人`、`/开枪`、`/发言完毕`、`/投票`、`/结束游戏`、`/关闭狼人杀房间`。

`/关闭房间` 是通用关闭入口：当前群是狼人杀房间时关闭狼人杀，是璀璨宝石房间时关闭璀璨宝石。只有房主可以关闭。

## 开发说明

- Runtime 插件路径：`data/plugins/astrbot_plugin_new_elysium_cardroom`
- Source 插件路径：`plugins/astrbot_plugin_new_elysium_cardroom`
- 两份镜像需要同步。
- `metadata.yaml` 的 `repo: ""` 是有意设置，避免 AstrBot 更新逻辑把本地 fork 拉回原狼人杀插件线。
- 新增桌游时，确定性规则写在 Python 引擎中；角色声纹、风格、非最优倾向写在适配 prompt 或 skill 文档中。
