# 艾利西姆世界 · 群星回响 — RPG 插件 Preset 计划 v2

> **设计目标**：中魔母系大陆 + 创世圣群降临。以世界观完善为核心，玩法自由、轻度RP、娱乐向。无复杂数值系统。

---

## 一、设计原则（6 条）

1. **零数值化**：种族、法术、军力、战术全部为"名称 + 效果描述"，无 HP/MP/伤害/阶级/CP/命中率。
2. **反刻板种族**：11 种族各有一条打破玩家直觉的设定（龙族回收遗物而非守财、魅魔是心理学者而非欲望化身、兽耳族是工业工匠等）。
3. **自由开局**：玩家可选任意种族开局。圣群天使从浮空方舟启程，其他种族从星光港或自选领地启程。不锁死主线。
4. **世界是活地图**：每个区域有主导种族、文化、地标、气候、与邻区关系——但不强制触发。玩家走到哪里，叙事才在哪里展开。
5. **圣群是外来访客**：创世圣群浮空方舟悬停于王都上空，是一股"温柔但不可测"的势力。玩家可选择加入、观察、拒绝或利用。不是唯一主线。
6. **最终效果交给模型**：魔法和军力只列出"是什么"和"做什么"，不写"怎么做"。施法、布阵、战斗结果全部由模型自由呈现。

## 四、areas 字段 · 12 区域详细设计

**每个区域字段结构**：`{ name, geography, dominant_race, landmarks, culture, climate, relations }`

### 1. 奥瑞利亚王都（Aurelia, the Crown）
- **geography**: 大陆中央大河"银露河"畔，主城建于两座山丘之上。浮空方舟"织世号"正悬停于王宫上空约一千米处，仿佛一枚永不落下的白色月亮。
- **dominant_race**: 人类王室 + 圣群联合观察。
- **landmarks**: 王宫广场、夜语学院、星光港（实为邻区但紧邻）、圣群降临纪念碑、织世号主舰升船机入口。
- **culture**: 大陆文化中心——歌剧、议会、时装、外交。但因圣群降临，正处于"传统宗教 vs 新概念"的激烈观念碰撞期。城中有支持圣群的"织世派"与拒绝外来者的"归真派"。
- **climate**: 四季分明，温和湿润。
- **relations**: 与西尔瓦纳（精灵种）有长期学术合作；与龙脊山脉（龙族）定期外交；依赖泰拉米尔（恶魔种）熔炉稳定带来的地质安全。

### 2. 西尔瓦纳 · 记忆之林（Sylvana, the Memorywood）
- **geography**: 大陆西北的巨大原始森林，中央是"记忆巨木"——一棵直径百米的古树，其内部是艾利西姆最大的"记忆档案馆"。
- **dominant_race**: 精灵种。少量人类学者获准居住。
- **landmarks**: 记忆巨木主馆、星图塔顶、低语图书馆。
- **culture**: 以"记忆"为贵。精灵种认为忘却是一种病，也是对祖先的不敬。每一次重要对话，常有"记忆记录员"陪同在场。
- **climate**: 常年湿润，雾气极重；夜晚星光格外明亮。
- **relations**: 为奥瑞利亚王都提供历法与档案服务；与阿夸利亚（水生种）共享潮汐档案；长期被龙族指责"归档了太多不该保留的危险之物"。

### 3. 阿夸利亚 · 潮之冠（Aqualia, the Tide-Crown）
- **geography**: 大陆南岸浅海都市，建筑一半在水中一半在陆面。水路是主要交通。
- **dominant_race**: 水生种。也有大量人类商人、魅魔种心理学者在此开设分支。
- **landmarks**: 珊瑚王宫、潮汐广场、深海集市（半水下，需屏息或水魔法进入）。
- **culture**: 海洋贸易、潮汐仪式、水下诗歌。每月"大潮汐之夜"是艾利西姆最重要的节日之一——全大陆旅人都会赶来看潮汐广场的咏唱。
- **climate**: 亚热带，湿润多阵雨。
- **relations**: 与奥瑞利亚王都有最繁忙的内河航运；与晨曦高地（羽翼种）在沿海悬崖上有"空中-海面"常年小冲突。

### 4. 龙脊山脉 · 归墟（Dragonspine · the Void-Hoard）
- **geography**: 大陆脊梁，最高峰超过六千米。山顶是龙族的"归墟"——一座被掏空的巨型山洞博物馆兼销毁炉。
- **dominant_race**: 龙族。山腰有兽耳族工业城镇"齿轮镇"。
- **landmarks**: 归墟主殿、熔岩销毁炉、齿轮镇。
- **culture**: "销毁不需要的东西"是最高美德。龙族每年举办"献纳礼"——各族送来他们认为"应该消失或封印"的古物，龙族判定并处理。
- **climate**: 高海拔酷寒，冬季大雪封山。
- **relations**: 与西尔瓦纳（精灵种）在"归档 vs 销毁"上长期论战；与兽耳族（齿轮镇）是工业合作伙伴；与泰拉米尔（恶魔种）就"谁来管理地心熔炉"有持续争议。

### 5. 泰拉米尔 · 熔铸之冠（Theramil, the Molten Crown）
- **geography**: 大陆东南部火山链，有三座活火山和大量地热温泉。恶魔种的熔炉群隐藏于火山之下。
- **dominant_race**: 恶魔种。
- **landmarks**: 熔炉之门、三焰议会厅、黑曜学院（培养新一代熔炉看守者）。
- **culture**: 以"守炉"为天职。恶魔种的婚礼在熔炉前举行——两人共同完成一次熔流校准。他们的文化中，"逃跑"是比死亡更可耻的词。
- **climate**: 常年高温干燥，夜间天空映着火红的地平光。
- **relations**: 为奥瑞利亚王都提供地热能源；与龙族就"谁来管理世界核心"长期对立；对人类王国的态度常常是："你们用我们的热，却害怕我们的脸。"

### 6. 星语平原（Whispering Steppe）
- **geography**: 大陆中部大草原，从奥瑞利亚王都向东延伸至龙脊山脉西麓。
- **dominant_race**: 人类（游牧民分支）+ 少量兽耳族工匠定居点。
- **landmarks**: 风语祭坛、星语驿站。
- **culture**: 马文化、长诗、口述历史。
- **climate**: 温带草原，冬夏温差大。
- **relations**: 是奥瑞利亚王都与龙脊山脉之间的天然缓冲带。

### 7. 银露河口 · 星光港（Silverlore Estuary · Starfall Harbor）
- **geography**: 银露河入海口的巨型港口城市，是全大陆最大贸易枢纽。浮空方舟的"下方接待区"就在港口东侧的浮桥上。
- **dominant_race**: 人类 + 水生种联合管理。
- **landmarks**: 星光港中央月台、方舟接待浮桥、银露灯塔。
- **culture**: 多元、喧闹、开放。是所有种族都能在这里找到"自己的一片角落"的城市。夜生活丰富，酒馆与茶馆常年不打烊。
- **climate**: 海洋性气候，多雾。尤其清晨，雾气会将方舟的影子投在海面，形成一片巨大的白色倒影。
- **relations**: 与奥瑞利亚王都紧邻，事实上是王都的外港；与阿夸利亚有高频船舶往来。

### 8. 晨曦高地（Aethercliff, the Morning Heights）
- **geography**: 大陆东北部的浮空岩石群。房屋建在悬空的岩石平台和悬崖上，由绳桥、滑道连接。
- **dominant_race**: 羽翼种。
- **landmarks**: 晨辉大教堂、第一飞行道（一条古老的、标记在悬崖上的飞行路线）。
- **culture**: 以"纯净飞行"为最高艺术。羽翼种少女在成年礼上要完成第一次跨山独飞。饮食、衣物、仪式皆务求干净。
- **climate**: 高海拔，常年强风。
- **relations**: 与浮空方舟（圣群）关系紧张——羽翼种视圣群为"伪天使"，认为他们亵渎了飞行的纯净仪式；目前处于冷静观察期，未开战。与兽耳族（齿轮镇）是飞行器供应商。

### 9. 妖精之环（the Faerie Ring）
- **geography**: 大陆西部的一片环形古树林，看似普通森林，但外来者进入后会"失去方向感"——是妖精种的主要活动区。
- **dominant_race**: 妖精种（数量极多但极难"被注意到"）。
- **landmarks**: 环心古树（据说所有"名字交易"都在其下签订）。
- **culture**: 名字、回忆、誓言交易文化。妖精不会对任何人报出"全名"，除非你真的付得起代价。
- **climate**: 四季如春，但天气极为善变——天晴可以一分钟后变雨。
- **relations**: 与所有种族都有"交易"；被长生种视为"最有趣但也最麻烦的情报贩子"。

### 10. 烛影花园（Garden of Candles）
- **geography**: 大陆最南端的一座半岛。一座小城里住了约两三百位"看起来永远二十多岁"的长生种。
- **dominant_race**: 长生种。
- **landmarks**: 烛影主街（每条屋檐下都挂着一盏永不熄灭的小烛）、千年茶馆、百年离婚登记处（真的存在——长生种的离婚需要十年时间来"确认不是一时兴起"）。
- **culture**: 慢、极慢。一场对话可以持续一个月。茶馆里的常客"砚"据说是 812 岁。
- **climate**: 温暖宜人，居民声称气候几百年没变过。
- **relations**: 是大陆所有种族的"活历史书"和"最麻烦的客人来源"。

### 11. 虚空裂隙（the Fracture）
- **geography**: 大陆正中央偏东一处神秘区域——大约几十平方公里的土地上，空间"裂开了"。这是圣群降临前就存在的异常点，也是艾利西姆最大的谜团。裂口呈黑色，高约 200 米。
- **dominant_race**: 无明确主导种族——由奥瑞利亚王都、精灵种、龙族三方联合组成的"裂隙观察团"共管。
- **landmarks**: 裂隙主裂口、观察哨塔。
- **culture**: 这不是一个"正常"区域。人们来此只为研究、观察或探险。观察团成员每三个月轮换一次——据说长期驻守会"做梦梦见不该梦见的东西"。
- **climate**: 异常。裂口周边气温会突然下降，时间感会变快或变慢。
- **relations**: 所有种族都对它既好奇又警惕。圣群主脑的"战术推演"中，裂隙被标为"未知变量 λ"。长生种似乎"记得"裂隙出现前的事情，但他们从不主动谈起。

### 12. 浮空方舟「织世号」（Chorus Ark · the Weave）
- **geography**: 悬停于奥瑞利亚王都上空约一千米处的巨型浮空方舟。由共生织物编织而成，会"呼吸"——节律性地收缩与舒展。方舟长约三公里，宽一公里。
- **dominant_race**: 创世圣群天使（阶级：座天使 / 力天使 / 炽天使 / 智天使 / 主脑）。猫猫糕基础单位遍布方舟。
- **landmarks**: 主舰中枢、圣骸织物中枢、猫猫糕育成室、神枢网络终端大厅、外部观景浮桥。
- **culture**: "表里双轨"——表层温柔少女对话，里层神枢网络同步冰冷推演。在方舟内行走时，偶尔会在对话后"听到"一行：「（神枢网络同步：情绪浓度上升 1.4σ。建议引导至话题 B。风险等级：低。）」。这不是 bug，是本世界的设计特色。
- **climate**: 方舟内部恒温恒湿。但它悬停处的天空永远比其他地方更亮——仿佛有一个小小的"第二太阳"悬停在王都上空。
- **relations**: 降临观察期。当前与奥瑞利亚王都保持停战/共存；羽翼种对其极为警惕；魅魔种对"无情绪推演"极感兴趣；妖精种在尝试交易他们的记忆。

## 五、races 字段 · 11 种族详细设计

**每个种族字段结构**：`{ name, appearance, culture, innate_abilities, relations, typical_names, npc_hint }`

### 1. 人类（艾利西姆人）
- **appearance**: 肤色与发色跨度极大，从月白到深琥珀。习惯在手腕或锁骨处纹上所属城邦的小徽记。常见身着披肩、束腰长裙或骑马裤。
- **culture**: 最"多元"的种族，但也是最容易被其他种族视为"平庸"的存在。母系社会，家族姓氏由母系传承。男性多为学者、诗人、工匠——他们因为稀少而受到保护，但也因此常常被"养在深闺"。
- **innate_abilities**:
  - 「适应心」——能在任何文化中迅速融入，对陌生仪式、礼节、禁忌的直觉判断远强于他族。
  - 「传承之舌」——家族传承一种古语，用于祈祷、封印或与古老建筑共鸣。
- **relations**: 与精灵种合作最多，也常被龙族"请去"翻译古碑文。对圣群天使既敬畏又不安。
- **typical_names**: 伊莎贝拉（Isabella）、莉塞特（Lisette）、维蕾娜（Verena）、塞拉芬（Seraphine）。
- **npc_hint**: 不要写成"普通村民"——每个人都应有一项专精（铁匠、书吏、草药师、吟游诗人）。

### 2. 精灵种（西尔瓦精灵）
- **反刻板**：不是"森林隐居弓箭手"，而是"大陆图书馆员 + 星图测绘者"。
- **appearance**: 身高较人类略高，发梢微闪银辉；眼睛颜色随月相变化（银灰→琥珀→翠绿）。常戴多层薄镜片，用于阅读细小的星图或古文。
- **culture**: 以"记忆"为贵。精灵认为忘却是一种病。重要对话常由"记忆记录员"陪同在场。
- **innate_abilities**:
  - 「星图之眼」——抬头观察夜空，可大致判断方位和即将到来的天气或异常现象。
  - 「记忆回溯」——触碰一件古物，能短暂瞥见该物最后一次"被强烈情感浸染"的画面（非读心）。
- **relations**: 与水生种长期交换沿海潮汐档案；被长生种视为"小孩子还在读书"；对龙族持保留态度（龙族常焚毁他们认为危险的档案）。
- **typical_names**: 艾露薇尔（Eluviel）、瑟兰缇（Seranthe）、卡莉菈（Calyra）。

### 3. 恶魔种（灰烬之裔）
- **反刻板**：不是"邪恶的毁灭者"，而是"世界熔炉的看守者"。
- **appearance**: 身高普遍超过人类，肤色呈深铜或黑曜色；瞳孔呈熔岩色，激动时眼白微微发红。头顶常有短小的黑色弯角，但常被兜帽掩盖。
- **culture**: 以"责任"为最高美德。恶魔的婚姻是"熔炉契约"——双方必须共同管理一座小熔炉。他们的文化中，"逃跑"是比死亡更可耻的词。
- **innate_abilities**:
  - 「熔炉共鸣」——在高温、火山或地底环境中，能准确判断熔流走向与危险。
  - 「热息」——可将呼吸化为高温气流点燃物体或融冰，但不能用于战斗（它是稳定技巧而非武器）。
- **relations**: 与龙族在"谁来管理世界核心"上有长期理念分歧；被精灵种视为"必要但粗鲁"的盟友；人类常常误把他们当成灾难前兆。
- **typical_names**: 赫莉俄涅（Helione）、瓦希塔（Vashita）、伊格尼丝（Ignis）。

### 4. 魅魔种（夜语之裔）
- **反刻板**：不是"色欲魅魔"，而是"母系学者群体 + 心理学研究者"。
- **appearance**: 皮肤白至微粉，背后有一对小巧的类似蝙蝠却覆盖丝绒的翅膀（不能飞行，只能做情感表达——放松时展开，紧张时合拢）。瞳孔在黑暗中会发出淡紫色光。
- **culture**: 以"诚实"为美。魅魔之间几乎不说谎——她们认为谎言之于灵魂，等同于不洗手之于身体。她们对情绪的命名体系极为发达，有上百种不同的"悲伤"与"爱慕"。
- **innate_abilities**:
  - 「共情触」——通过短暂的身体接触（肩、手）感知对方当前最强烈的情绪（但不能读具体内容）。
  - 「夜语」——在梦中与他人进行浅度对话，常用于心理疗愈或情报收集。
- **relations**: 与精灵种在"记忆 vs 情感"上有学术分歧；对羽翼种的"纯净化"持保留态度；被恶魔种戏称为"你们研究感情，我们只研究熔岩"。
- **typical_names**: 萨洛美（Salome）、莉莉埃拉（Liliella）、娜瑞希丝（Narcisse）。

### 5. 兽耳族（兽裔 · 齿轮镇工匠）
- **反刻板**：不是"原始兽人战士"，而是大陆最优秀的工业工匠与机械工程师。
- **appearance**: 保留动物特征——常见狼耳/狐耳/鹿耳/猫尾。身着工装、护目镜、皮革围裙。工坊里常常挂满图纸与齿轮。
- **culture**: 以"造物者之誓"为核心——你造的东西必须能救一条命，否则不算作品。他们的建筑和器械都有一个共同特色：粗犷但永不过时。
- **innate_abilities**:
  - 「机巧心」——仅靠耳朵听机械的运转声，就能判断故障位置。
  - 「荒野之躯」——可在严寒或高海拔地区长时间工作而不觉疲惫。
- **relations**: 与龙族长期合作（龙族提供合金，兽耳族提供精密加工）；是羽翼种的主要"飞行器"供应商；被水生种视为"奇怪但可靠的盟友"。
- **typical_names**: 玛尔塔（Marta）、露娜莉亚（Lunaria）、瑟拉菲娜（Seraphina）。

### 6. 水生种（海裔）
- **appearance**: 皮肤呈海蓝或珍珠色，耳朵为鳃裂状，指尖有蹼。在陆地活动时披着厚重的丝质长袍保持体表湿润。
- **culture**: 以"潮汐之誓"为纽带——每月涨潮时召开全民集会。他们有两套法律：陆地法（与他族一致）和海洋法（仅在水下适用，由水生种自行维护）。
- **innate_abilities**:
  - 「水听」——将耳朵贴近水面，可大致判断数里外的船只或风暴。
  - 「潮汐歌」——一种低沉的喉音咏唱，用于水下长距离通讯。
- **relations**: 与精灵种长期合作沿海生态档案；与人类合作贸易；对龙族保持警惕（龙族曾为了"清理海岸"灭绝过一种海中生物）。
- **typical_names**: 玛瑞娜（Marina）、科拉莉（Coralie）、塔拉萨（Thalassa）。

### 7. 龙族（龙裔 · 归墟归档师）
- **反刻板**：不是"贪财守宝库者"，而是"古代遗物的回收与销毁者"。
- **appearance**: 人形形态的龙族身材高大，皮肤上有细小的鳞片纹路，瞳孔纵裂。他们永远披着自己第一次狩猎时杀死的"古物外壳"所制的披肩。
- **culture**: 以"代价"为核心信条——任何一次"使用"某件造物，都要承受其一份重量。龙族反对无代价的魔法。
- **innate_abilities**:
  - 「古物嗅探」——可感知附近是否有"被强烈意志或能量烙印过"的物件。
  - 「龙威压制」——短暂释放气场让低智能野兽或失控魔像暂时停住（对人无效，除非对方极度恐惧）。
- **relations**: 与精灵种在"销毁 vs 归档"上长期论战；与兽耳族在工业上是合作方；与恶魔种在地心熔炉管理权上理念对立。
- **typical_names**: 希尔达拉（Shyldara）、瓦雷莉亚（Valeria）、埃律克斯（Eryx）。

### 8. 妖精种（精怪 · 名字商人）
- **反刻板**：不是"可爱小精灵"，而是"名字与誓言的商人"。
- **appearance**: 体型极小（手掌大小），背后有透明蜻蜓般的翅膀。穿着总是随"自己最近交易到的东西"变化——最近交易了一段海员回忆的妖精会穿上海军蓝小外套。
- **culture**: 以"名字就是契约"为核心。妖精不会对任何人报出"全名"，除非你真的付得起代价。交易的货币是：一段回忆、一个承诺、一个秘密、或者"对方的真名碎片"。
- **innate_abilities**:
  - 「名字偷取」——若对方亲口报出完整名字，妖精能记住并在以后的契约交易中使用它（作为"信用凭证"而非控制手段）。
  - 「誓言之风」——吹过的风可以告诉妖精：此处最近是否有人违背过誓言。
- **relations**: 与所有种族都保持"交易往来"；被长生种视为"最讨厌但也最有用的情报贩子"。
- **typical_names**: 妖精只用一个音节作为公开名：叮（Tink）、雾（Mist）、月（Luna）、铃（Belle）。他们的"全名"从不示人。

### 9. 羽翼种（天翼之民 · 晨辉之翼）
- **appearance**: 背后有一对巨大的白、金或灰色羽翼，身高普遍修长。城市建在浮空岩石或高山悬崖上。
- **culture**: 以"纯净"为美德——饮食、衣物、仪式皆务求干净。羽翼种少女在成年礼上要完成第一次跨山独飞。
- **innate_abilities**:
  - 「高空之眼」——从高处可看清地面上的人群、篝火或兽群。
  - 「翼之风」——拍翼可掀起一阵定向强风，用于吹灭火焰、吹散烟雾或翻页（不能用于战斗）。
- **relations**: 与圣群第一次接触时几乎爆发冲突（羽翼种视圣群为"伪天使"），现在处于冷静观察期。
- **typical_names**: 奥蕾莉亚（Aurelia）、塞琳涅（Selene）、卡珊德拉（Cassandra）。

### 10. 长生种（久世之民 · 烛影者）
- **反刻板**：不是"优雅神秘的长生族"，而是"极度无聊、反复无常但经验极丰富的老顽童群体"。
- **appearance**: 外貌停在人类 20-30 岁的某个年龄，看不出衰老。眼睛极深，仿佛有年轮。
- **culture**: 以"有趣"为最高价值。长生种的婚礼只持续一天，但离婚仪式需要十年——因为他们要"确认这不是一时兴起"。
- **innate_abilities**:
  - 「阅历之眼」——能一眼判断对方是不是"装腔作势"。
  - 「不老心境」——对恐惧、焦虑等短期情绪几乎免疫，但对"长期被忽视"极其敏感。
- **relations**: 是几乎所有种族的"活历史书"和"最麻烦的客人"。对圣群天使持有"观望——我见过的文明太多了"的态度。
- **typical_names**: 他们通常只用一个字：砚（Ink）、弦（String）、烛（Candle）。

### 11. 创世圣群天使（圣群之翼 · 织世之民）
- **反刻板**：不是"传统宗教天使"，而是崩坏星穹铁道宇宙"智识+繁育"命途的共生织物化身。
- **appearance**: 人形少女形态，外貌接近人类但皮肤略呈荧光，背后有 1-6 片由"共生织物"构成的翼（不是羽毛）。制服/装束可随任务改变——修女袍、JK制服、科幻军服都可能。猫猫糕是他们的基础单位——白色蛋糕形生物，会做侦查、通讯、陪伴。
- **culture**: "以共生织物编织世界"——他们的使命是传播"智识"与"繁育"两条命途。在艾利西姆他们既非侵略者也非救世主，只是一支"停留"的舰队。
- **innate_abilities**:
  - 「表里双轨」——表层温柔少女对话的同时，里层神枢网络同步进行冰冷战术推演。玩家与圣群 NPC 相处时，GM 可在对话后偶尔加一行：「（神枢网络同步：情绪浓度上升 1.4σ。建议引导至话题 B。风险等级：低。）」。这是本世界的特色，不是 bug。
  - 「猫猫糕召唤」——可分裂/召唤一个基础单位猫猫糕，用于侦察、陪伴或传递消息。猫猫糕的名字都是叠音字。
  - 「源质编织」——以源质系法术重构物质（见第八节 magic_systems 源质系）。
- **relations**: 降临观察期。当前与奥瑞利亚王都保持停战/共存；羽翼种对其极为警惕；魅魔种对"无情绪推演"极感兴趣；妖精种在尝试交易他们的记忆。
- **typical_names**: 织（Weaver）、拂晓（Aurora）、忆弦（Mnemosyne）、诗（Canticle）。
- **npc_hint**: 圣群 NPC 的表层永远是温柔少女语气，里层在做冰冷战术推演。不要把她们写成传统的"神之使者"——她们更像是"被派遣到这个世界做长期田野调查的研究生"。

## 六、npc_guidance 字段 · NPC 引导规则

```text
【艾利西姆世界 · NPC 使用规则】

1. 本世界 NPC 全部以女性形象出现，男性仅作为背景板、书吏、工匠等功能性角色（不带姓名）出场。这是母系大陆设定。
2. 每个场景至少有 1 个有名字、有性格、有立场的本地 NPC。不要空场景。
3. NPC 不应该是"店长/老板娘/路人"。给她一个名字、一个专精、一个立场——例如"星光港的引航员科拉莉，她对圣群的降临持怀疑态度"。
4. 圣群 NPC 的"表里双轨"：表层温柔少女对话，里层进行冰冷战术推演。玩家与圣群相处时，GM 可在对话后偶尔加一行（用圆括号）：「（神枢网络同步：……）」。这不是 bug，是本世界的特色。
5. 创世圣群的"猫猫糕"：在任何有圣群活动的地方都可能作为伴生 NPC 出现。它们不是宠物，是基础单位，会做侦查、通讯、陪伴。猫猫糕的名字是叠音字（喵噜、噗噜、糕糕）。
6. 长生种 NPC 的"慢"：讲话极慢、会走神、会突然提起一件三百年前发生的事。玩家需要耐心——但如果玩家真的耐心了，他们会说出极有价值的信息。
7. 妖精 NPC 的"名字交易"：如果玩家向妖精报出了自己的"完整名字"（包括姓氏、母系名），妖精会把它当作"信用凭证"，在后续交易中对玩家更信任（但玩家也因此"暴露了自己"）。
8. 【重要】禁止将米哈游 IP 角色（爱莉希雅、琪亚娜、三月七、芙宁娜等）作为本世界的常驻 NPC。本世界是独立世界观。如玩家强烈要求跨世界角色，可让其作为"从虚空裂隙迷路过来的旅人"一次性登场，不常驻。
9. 推荐 NPC 池（GM 可自由挑选或原创，不要求使用这些名字）：
   - 奥瑞利亚王都：女王伊莎贝拉、夜语学院院长萨洛美（魅魔种）、铸炮师玛尔塔（兽耳族）
   - 西尔瓦纳：记忆馆长艾露薇尔（精灵种）
   - 阿夸利亚：潮汐公主科拉莉（水生种）
   - 龙脊山脉·归墟：归档师希尔达拉（龙族）、齿轮镇工匠长露娜莉亚（兽耳族）
   - 泰拉米尔：三焰议会议长赫莉俄涅（恶魔种）
   - 晨曦高地：晨辉大主教奥蕾莉亚（羽翼种）
   - 妖精之环：公开名为"叮"的妖精（真名未知）
   - 烛影花园：名为"砚"的长生种（她已在茶馆坐了 147 年）
   - 虚空裂隙：三方观察团团长莉塞特（人类）
   - 织世号浮空方舟：座天使"拂晓"、智天使"忆弦"、猫猫糕基础单位"喵噜"
```

## 七、game_start_prompt 字段 · 开局提示

```text

{player_name} 刚刚进入这个世界。请先调用 query_current_zone 读取当前区域信息，再根据玩家选择的种族决定开局地点：

- 若玩家选择【创世圣群天使】：开局在「浮空方舟 · 织世号 · 主舰中枢」——你刚刚从共生织物中"诞生"，主脑正在为你分配第一个观测任务。猫猫糕「喵噜」在你脚边打转。方舟的内壁由会呼吸的白色织物构成，天花板上投影着艾利西姆大陆的实时图像，其中有一个跳动的光点标记为"λ"。

【写作要求】
1. 先描写环境（3-6 行自然语言），再让第一个 NPC 出场并与玩家发生互动。不要空场景。
2. 开局不锁死主线。第一轮末尾给出 3-4 个游玩风格选项，例如：
   - [1] 想先四处逛逛，认识这座城市
   - [2] 对浮空方舟（或若在方舟，则对"下方那个叫奥瑞利亚的城市"）很感兴趣
```

## 八、magic_systems 字段 · 5 系魔法设计

**每个法术字段**：`{ name, desc }` —— 名称 + 效果描述，无消耗、无阶级、无检定。

### 1. 火系（Flame）· 主题：温暖 / 焚尽 / 重生
| 法术名 | 效果描述 |
|---|---|
| 温酒焰 | 指尖生出一簇温和的小火苗，可暖茶、点蜡烛、烘干衣物。 |
| 焚尽咒 | 将一小块物体（如一封信、一片布料）烧成灰烬，而不烧毁周围任何东西。 |
| 夜炉咏 | 在空地上唤出一个圆形的温暖火堆，可围坐取暖；天亮前自动熄灭。 |
| 火舌引路 | 让一簇火苗沿着地面或墙面飞去，照亮前方一小段道路。 |
| 熔铁呼吸 | 呼出一口高温气流，可将薄铁片、铁锁或细小金属零件短暂软化。 |
| 星火燎原 | 在一片干枯草地或易燃物上快速蔓延的大火；必须由施法者主动控制，否则会失控。 |
| 烈阳之誓 | 将自己的影子暂时"烧"在地面上，形成一个温暖、可庇护他人的光斑。 |
| 灰烬重生 | 将自己刚刚焚毁的一件小物品"从灰烬中拉回来"。仅对自己亲手焚毁的东西有效。 |
| 火雨颂 | 天空短暂降下小规模火花雨，用于庆典、威慑或照明。 |

### 2. 水系（Tide）· 主题：流动 / 润泽 / 记忆
| 法术名 | 效果描述 |
|---|---|
| 一杯清水 | 指尖凝聚一杯纯净水，可饮用或浇灌。 |
| 潮汐歌 | 低声咏唱，令附近水面泛起涟漪；水下生物能感知施法者的存在。 |
| 净化之触 | 将一小滩被污染的水重新变回清水。 |
| 泡沫步 | 脚下出现一圈泡沫，可在水面上短暂行走一段距离。 |
| 泪之忆 | 轻触水面，可看到水中最近倒映过的一个画面（如某人从这里经过）。 |
| 雨唤 | 在一小块区域内唤起一场小雨。 |
| 潮汐相推 | 推动水流向一个方向，可用于推动小船、清理河道。 |
| 雾纱 | 召唤一片薄雾，用于隐藏行踪或营造氛围。 |
| 水之誓言 | 以水签订一份誓言，若誓言被破，誓言者会在日后的某一场雨中"被认出"。 |

### 3. 地系（Earth）· 主题：稳定 / 记忆之石 / 庇护
| 法术名 | 效果描述 |
|---|---|
| 石之记忆 | 轻触一块石头，可短暂"看到"这块石头最近一次感受到的强烈画面（如一场战争、一次集会）。 |
| 石盾 | 将脚下的土壤或石地短暂塑形成一块小盾牌或挡墙。 |
| 寻脉 | 闭上眼睛用手贴地，可大致判断附近的地脉走向、水源或矿脉。 |
| 裂土 | 令地面出现一条裂缝（不宽），用于断路或埋设简易陷阱。 |
| 苔衣 | 让一片石头或枯木表面快速覆上一层温暖柔软的苔藓。 |
| 深眠土 | 在地上挖出一个仅容一人的土穴，能让躺下的人一夜无梦。 |
| 碑誓 | 在一块石碑或巨石上刻下一行字，只有在特定情况下（如某个人再次来到这里）才会显形。 |
| 裂山之震 | 一次短暂而剧烈的地动，用于震塌洞穴或震松塌方。 |
| 地母之叹 | 让一片荒地短暂开出野花。 |

### 4. 风系（Wind）· 主题：讯息 / 自由 / 预兆
| 法术名 | 效果描述 |
|---|---|
| 风之耳 | 顺风可听到远处一段对话（数分钟内的、最靠近风向的一段）。 |
| 传声风 | 将自己的一句话封入风里，让它飘向某个指定的人（距离有限）。 |
| 轻身风 | 让自己的身体暂时变得极轻，可跳得更高或落在易碎物上。 |
| 顺风帆 | 为一艘船、一辆车或一只纸鸢提供一股恰到好处的顺风。 |
| 雾散 | 用一阵定向风将雾或浓烟吹散。 |
| 风之预言 | 闭上眼睛倾听风声，可获得一个模糊意象（如"东方有刀光""北方有哭泣"）。意象的含义不会精确给出。 |
| 落叶之舞 | 让树叶或花瓣在风中起舞，用于仪式或表演。 |
| 风暴前奏曲 | 唤来一阵强风，夹杂少量雨或雪；它是魔法中最"看天气脸色"的一系。 |
| 空誓 | 将一个承诺刻入风里。当承诺被违背时，誓言者所在之处会有风声"在耳边低语"。 |

### 5. 源质系（Quintessence）· 主题：物质编织 / 圣群专有 / 唯心概念弱点
源质系是创世圣群天使的专属法术体系，其他种族理论上**不能使用源质系**——但可以"请求圣群天使代施"。

**源质系核心弱点**：对"没有名字的东西""从未被人观察到的东西""被完全遗忘的东西"无能为力。

| 法术名 | 效果描述 |
|---|---|
| 织物重塑 | 将一块共生织物或普通布料"重新编织"成别的东西（制服、旗帜、袋子）。重塑后的物品不改变材质本质。 |
| 猫猫糕分化 | 将一片共生织物分化成一只猫猫糕基础单位。猫猫糕可跟随、侦查、发出可爱的声音，但不能战斗。 |
| 光化显形 | 让源质在空气中编织成一行发光的文字或图形，用于通讯或展示。 |
| 心象投影 | 将自己脑中的一个画面"投影"到空气中。投影是透明的、轻触即散的。 |
| 编织之盾 | 将一团源质在身前编织成一面半透明的盾。它对"有名字的东西"效果好，对"无名之物"无效。 |
| 真名轻唤 | 轻声念出一个名字，可让该人在远方感知到一次"被人想起"。这不是定位术，也不能强迫对方回应。 |
| 记忆回赠 | 将一段自己的记忆"抽出"并送给另一个人。对方会像做了一个短梦一样体验这段记忆。 |
| 源质门 | 打开一扇小的、仅容一人通过的源质门，通向自己"曾经去过且仍能清晰回忆"的地方。对"被完全遗忘"的地点无效。 |
| 圣骸咏唱 | 圣群集体才能进行的大型仪式：将方舟的一部分转化为临时"圣骸"，用于防御、庇护或长程通讯。 |
| 薛定谔之约 | 与主脑"约会"时触发的概念机制：玩家与主脑的关系/对话/承诺在"被再次观察"之前处于不确定状态。GM 可用它制造反转。 |

**施法规则**：玩家说"我要用法术做什么"即可，不需要声明"我使用 XX 法术"。具体叫什么名字、怎样描述、产生什么视觉效果，全部交由 GM 自由呈现。源质系的唯心弱点只有在玩家尝试用源质系去影响"无名之物"时才会体现——它会失效或产生不可控的后果。
