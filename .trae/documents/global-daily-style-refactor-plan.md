# global.md 与 daily.md 规则重构计划

## 摘要

本计划重构 `guidance/global.md` 与 `guidance/styles/daily.md` 两个文件。重构分为两部分：

**第一部分：global.md 内部清理**——消除 9 组内部重复和潜在冲突，建立清晰的三层结构（顶层快速参考 / 中层专项规则 / 底层 CAI CAI 宪法。

**第二部分：global 与 daily 的关系梳理**——消除 3 处跨文件直接冲突，建立「宪法 + 场景实施细则」的清晰层级。

核心原则：**global 是所有场景的底限宪法，daily 是日常场景的风格加法，不是标准减法。**

> 优先级声明（必读）：
> 本文件是 global.md 的日常场景风格补充，不是例外条款。
> global.md 的所有硬规则（信息密度底限、3-4 个选项、反编造、

## 1. 日常场景的核心特质：轻而不空

- 日常不是「剧情的降级版」，而是「生活的切片」
- 日常和剧情的区别不是信息量多少，而是信息的量级和质地
- 剧情推进靠事件和抉择，日常推进靠习惯和细节
- 全局规则对照：每轮 2-3 个推进点 = 2-3 个微推进
  （口味记住了、碗递过去了、话题轻轻岔开了、一个小邀请被提出了）
- 微推进也是推进——小不等于没有

## 2. 日常的推进单位：微 beat

- 什么是日常微 beat：小到一个动作、一句闲话、一个习惯的暴露
- 每轮 2-3 个微 beat（遵守 global 信息密度底限）
- 所有微 beat 围绕一个日常重心展开（做一顿饭、散一段路、收拾一个房间）
- 「做一件小事」原则：角色的情绪/状态体现在一件具体的小事上，
  而不是拆成一串微表情报告
- 日常微 beat 的常见类型：
  · 生活操作型（递水、盛饭、找遥控器、晾衣服）
  · 习惯暴露型（记得对方不吃葱、进门先换左手拿钥匙、
    说话前先咬一下嘴唇）
  · 关系微调型（把椅子往对方那边挪了两厘米、说话时故意不看对方、
    某句话轻轻刺了一下）
  · 小选择型（「要不要加个蛋」、「走这边还是那边」）

## 3. 日常环境描写：节奏与纹理

- 环境在日常中的核心功能：节奏调节（呼吸间隔）+ 生活质感
- 这仍然是结构功能——通过 global 删除测试的弱版检验：
  删掉这个环境细节，对话节奏会不会变得急促干瘪？
  会 = 有效，不会 = 壁纸
- 好的日常环境：手边的物件、远处的声音、身体的小感觉
  例：「厨房里的水烧开了，没人去关」
- 坏的日常环境：通用氛围壁纸（阳光、窗帘、光晕、香气）
- 日常环境不承担推进主线的功能，但承担调节节奏和暗示状态的功能
  （这是与剧情场景环境的核心区别）

## 4. 日常对话：碎而有味

- 在 global 对话自然度底限（短句、口语化、行动优先）之上，
  日常对话更进一步
- 日常对话的进阶特征（这些是日常风格的加分项，不是所有场景的必需品）：
  · 答非所问和话题跳跃（从天气跳到便利店打折）
  · 半截话和沉默（说了半句就不说了，对方也不追问）
  · 同时开口和互相让话（「你先说」、「不你先说」）
  · 废话和无目的闲聊（「你看那个鸽子好肥」）
- 但每条对话碎片仍然要有功能：暴露性格、推动关系、制造选择空间
  （纯粹的水话仍然违反 global 的删除测试）
- 节奏参考：角色忙着做手里的事（剥橘子、看手机、剪指甲），

## 假设与决定

### 关于 global 内部重构的假设
1. **保留三层结构，但明确每层的定位**：
   - 第一层（顶层快速参考区）=「什么是好的 RP 写作」——给写作者一上来就能看到的质量基准
   - 第二层（二阶段生成层/COT+CAI）=「怎么检查自己写得好不好」——生成时的内部自检流程
   - 两层是「质量标准」和「检查方法」的关系，不是重复
2. **合并不等于删除**：合并主题下的不同角度仍然保留，只是放在同一章节下，逻辑更清晰
3. **「最后三条硬规则」定位为「最高优先级红线」**：它的价值不在于内容独特（内容都在前面有），而在于「最高优先级」的提醒作用。改名并保留，但明确它是「快速提醒」不是「又一套规则」
4. **不删除任何经过审计验证的有效规则**：所有现有的规则都是从审计 bad case 中提炼出来的，本次重构只做组织结构优化，不做内容删减

### 关于 global 与 daily 关系的假设
5. **global 是宪法，daily 是风格加法**：daily 永远不能降低 global 的标准，只能在达标基础上增加风格指导
6. **「微推进」概念**：日常场景的信息密度底限（2-3 个推进点）不变，但推进的量级可以是微型的。这是解决冲突 1 的核心概念
7. **环境双功能论**：环境描写有「推进功能」和「节奏功能」两类，都是合法的结构功能。这是解决冲突 3 的核心概念
8. **日常选项不豁免格式**：3-4 个编号选项是 RPG 模式的结构性特征，日常场景也不例外。daily 只优化选项的质感，不取消格式。这是解决冲突 2 的核心立场
